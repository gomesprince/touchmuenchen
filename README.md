# Touch München

Static website for the Touch München community.

## Website

The site provides information about social Touch Rugby in Munich, including the regular Sunday session and contact links.

## Regular session

- Sunday
- 10:00–12:00
- Englischer Garten, Munich
- All levels welcome
- Mixed and social Touch Rugby

## Contact

- Instagram: https://www.instagram.com/touchmuenchen/
- Facebook: https://www.facebook.com/groups/touchmuc/
- Meetup: https://www.meetup.com/munchen-touch-rugby-social-sunday-game-in-englischer-garten/
- Email: touchmuenchen@googlemail.com
